# **App Name**: AdPulse

## Core Features:

- Event Attribution Script: A lightweight JavaScript tracker to capture visitors, sessions, UTMs, fbclid, and gclid, automatically syncing to the backend.
- Conversion Webhook Receiver: Automated endpoints to process sales and refund events from platforms like Kiwify, Hotmart, and PerfectPay into the Supabase database.
- Meta Ads Sync Tool: Integration tool to import spend, impressions, and click data from Meta Ads API to calculate real-time ROAS.
- Real-time Metrics Dashboard: High-performance interface displaying ROI, CPA, and conversion funnels from captured event data.
- AI Path Mapping Tool: AI-powered tool to resolve unidentified conversions by analyzing behavioral patterns to attribute 'orphan' sales to specific campaigns.
- Unified Data Persistence: Relational storage of tracking data, events, and advertising costs using Supabase.
- Sales Lifecycle Logger: A state-driven logging system for lead journeys, tracking from PIX generation to approved purchase or refund.

## Style Guidelines:

- A sophisticated dark mode palette optimized for data visualization. Primary color: Electric Blue (#3B82F6). Background: Deep Onyx (#0F172A). Accent: Vibrant Indigo (#6366F1).
- Headline font: 'Space Grotesk' (Sans-serif) for a modern, tech-focused look. Body font: 'Inter' (Sans-serif) for maximum legibility in complex data tables.
- Minimalist, line-based icons with glowing subtle states to indicate active tracking and successful API pings.
- Information-dense grid layouts utilizing the 'Inter' font to ensure dashboard modularity and clear visual hierarchy of metrics.
- Fluid, high-refresh-rate transitions for real-time chart updates and subtle micro-interactions on button clicks.
